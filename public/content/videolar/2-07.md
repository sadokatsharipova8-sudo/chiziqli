# Tekislikda to'g'ri chiziq
@ ╱
> Assalomu alaykum! Bugun tekislikda to'g'ri chiziqning turli tenglamalari haqida gaplashamiz.

**2-semestr · 7-mavzu**

---

# Nega bu mavzu dolzarb?
@ ❓
> To'g'ri chiziq — eng sodda va eng ko'p ishlatiladigan geometrik obyekt. Masofa, burchak, kesishish nuqtasi, parallellik — bularning hammasi to'g'ri chiziq tenglamasi bilan hisoblanadi.

$$Ax + By + C = 0$$

---

# Hayotda: chiziqli bog'lanishlar
@ 📈
> Taksi narxi masofaga chiziqli bog'liq; yo'l qiyaligi — burchak koeffitsiyenti; kompyuter ekranida chiziq chizish algoritmi ham to'g'ri chiziq tenglamasidan foydalanadi. Ma'lumotlarga eng yaxshi to'g'ri chiziq — regressiya.

$$y = kx + b:\quad k\ \text{— qiyalik},\ b\ \text{— boshlang'ich qiymat}$$

---

# Tenglama turlari
@ 📋
> To'g'ri chiziqni turli usullarda berish mumkin: burchak koeffitsiyenti bilan, nuqta va normal vektor bilan, ikki nuqta orqali yoki o'qlardan ajratgan kesmalari orqali. Masala shartiga qarab qulayini tanlaymiz.

- $y = kx + b$
- $A(x - x_0) + B(y - y_0) = 0$
- $\frac{x - x_1}{x_2 - x_1} = \frac{y - y_1}{y_2 - y_1}$
- $\frac xa + \frac yb = 1$

---

# Normal vektor
@ ⟂
> Umumiy tenglamadagi A va B koeffitsiyentlar to'g'ri chiziqqa perpendikulyar vektor — normal vektorni beradi. Yo'naltiruvchi vektor esa minus B, A.

$$\mathbf n = (A;\ B) \perp \text{to'g'ri chiziq}$$

---

# Burchak va parallellik
@ 📐
> Ikki to'g'ri chiziq parallel — burchak koeffitsiyentlari teng; perpendikulyar — ko'paytmasi minus bir. Burchakning tangensi esa koeffitsiyentlar orqali topiladi.

$$k_1 = k_2\ \text{(parallel)},\qquad k_1k_2 = -1\ \text{(perpendikulyar)}$$

---

# Nuqtadan to'g'ri chiziqqacha masofa
@ 📏
> Nuqta koordinatalarini tenglamaning chap tomoniga qo'yib, modulini normal vektor uzunligiga bo'lsak — masofa chiqadi. Masalan, bir, ikki nuqtadan uch x plyus to'rt y plyus to'rt teng nol to'g'ri chiziqqacha masofa uch.

$$d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}} = \frac{|3 + 8 + 4|}{5} = 3$$

---

# Xulosa
@ 🎓
> Demak: to'g'ri chiziq birinchi darajali tenglama bilan beriladi, A va B — normal vektor. Parallellik, perpendikulyarlik, burchak va masofa oddiy formulalar bilan topiladi. Mashqlarda ikki nuqtadan o'tuvchi to'g'ri chiziq va masofa masalalarini yeching!

- $Ax + By + C = 0$, $\mathbf n = (A;\ B)$
- $k_1k_2 = -1$ — perpendikulyar
- $d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$
