## Nima yetishmaydi?

Chiziqli fazoda qo'shish va cho'zish bor, lekin:
- **uzunlik** yo'q;
- **burchak** yo'q;
- **perpendikulyarlik** yo'q.

Bularning hammasini bitta yangi amal — **skalyar ko'paytma** beradi.

---

## Skalyar ko'paytma

:::tarif
Haqiqiy chiziqli fazoda har bir juftga $(\mathbf x, \mathbf y) \in \mathbb R$ mos qo'yilgan va:
1. $(\mathbf x, \mathbf y) = (\mathbf y, \mathbf x)$ — simmetriklik
2. $(\mathbf x + \mathbf y, \mathbf z) = (\mathbf x, \mathbf z) + (\mathbf y, \mathbf z)$
3. $(\lambda\mathbf x, \mathbf y) = \lambda(\mathbf x, \mathbf y)$
4. $(\mathbf x, \mathbf x) > 0$, $\mathbf x \ne \mathbf 0$ — musbat aniqlanganlik

Bunday fazo — **Yevklid fazosi**.
:::

---

## Misollar

- $\mathbb R^n$: $(\mathbf x, \mathbf y) = x_1y_1 + \dots + x_ny_n$ — standart.
- $\mathbb R^2$: $(\mathbf x, \mathbf y) = 2x_1y_1 + 3x_2y_2$ — ham skalyar ko'paytma (vaznli).
- $C[a, b]$: $(f, g) = \displaystyle\int_a^b f(t)g(t)\,dt$.
- Matritsalar: $(A, B) = \operatorname{tr}(A^TB) = \sum a_{ij}b_{ij}$.

---

## Kontrmisol

$\mathbb R^2$ da $(\mathbf x, \mathbf y) = x_1y_1 - x_2y_2$ — skalyar ko'paytma **emas**:
$$((0, 1), (0, 1)) = -1 < 0.$$

4-aksioma buziladi. (Bunday «ko'paytma» nisbiylik nazariyasida ishlatiladi — Minkovskiy fazosi.)

---

## Uzunlik

:::tarif
$$|\mathbf x| = \sqrt{(\mathbf x, \mathbf x)}.$$
$|\mathbf x| = 1$ — normallangan; $\mathbf x^0 = \dfrac{\mathbf x}{|\mathbf x|}$.
:::

:::xossa
$|\lambda\mathbf x| = |\lambda||\mathbf x|$; $|\mathbf x| = 0 \iff \mathbf x = \mathbf 0$.
:::

:::misol
$\mathbf x = (1, 2, 2)$: $|\mathbf x| = 3$, $\mathbf x^0 = \left(\frac13, \frac23, \frac23\right)$.
:::

---

## Koshi–Bunyakovskiy tengsizligi

:::teorema
$$|(\mathbf x, \mathbf y)| \le |\mathbf x|\cdot|\mathbf y|,$$
tenglik $\iff$ $\mathbf x$, $\mathbf y$ chiziqli bog'liq.
:::

$\mathbb R^n$ da:
$$(x_1y_1 + \dots + x_ny_n)^2 \le (x_1^2 + \dots + x_n^2)(y_1^2 + \dots + y_n^2).$$

---

## Isbot

Istalgan $t$ uchun:
$$0 \le (\mathbf x - t\mathbf y, \mathbf x - t\mathbf y) = |\mathbf x|^2 - 2t(\mathbf x, \mathbf y) + t^2|\mathbf y|^2.$$

$t$ ga nisbatan kvadrat uchhad nomanfiy $\Rightarrow$ diskriminant $\le 0$:
$$4(\mathbf x, \mathbf y)^2 - 4|\mathbf x|^2|\mathbf y|^2 \le 0.$$ ∎

---

## Burchak

Koshi–Bunyakovskiydan $\left|\dfrac{(\mathbf x, \mathbf y)}{|\mathbf x||\mathbf y|}\right| \le 1$, shuning uchun:
$$\cos\varphi = \frac{(\mathbf x, \mathbf y)}{|\mathbf x|\,|\mathbf y|}.$$

:::misol
$\mathbb R^4$: $\mathbf x = (1, 1, 1, 1)$, $\mathbf y = (1, 0, 0, 1)$:
$$\cos\varphi = \frac{2}{2\sqrt2} = \frac{1}{\sqrt2},\quad \varphi = 45^\circ.$$
:::

---

## Burchak: funksiyalar

$C[0, 1]$ da $f = 1$, $g = t$:
$$(f, g) = \int_0^1 t\,dt = \frac12,\quad |f| = 1,\quad |g| = \sqrt{\int_0^1 t^2\,dt} = \frac{1}{\sqrt3}.$$
$$\cos\varphi = \frac{1/2}{1/\sqrt3} = \frac{\sqrt3}{2},\quad \varphi = 30^\circ.$$

Funksiyalar orasidagi «burchak»!

---

## Uchburchak tengsizligi

:::teorema
$$|\mathbf x + \mathbf y| \le |\mathbf x| + |\mathbf y|.$$
:::

Isbot: $|\mathbf x + \mathbf y|^2 = |\mathbf x|^2 + 2(\mathbf x, \mathbf y) + |\mathbf y|^2 \le |\mathbf x|^2 + 2|\mathbf x||\mathbf y| + |\mathbf y|^2 = (|\mathbf x| + |\mathbf y|)^2$.

Masofa: $\rho(\mathbf x, \mathbf y) = |\mathbf x - \mathbf y|$.

---

## Ortogonallik

:::tarif
$(\mathbf x, \mathbf y) = 0$ — **ortogonal**: $\mathbf x \perp \mathbf y$.
:::

**Pifagor teoremasi:** $\mathbf x \perp \mathbf y \Rightarrow |\mathbf x + \mathbf y|^2 = |\mathbf x|^2 + |\mathbf y|^2$.

:::savol
$\mathbf x = (1, 2, -1, 3)$, $\mathbf y = (2, 1, a, 0)$ qaysi $a$ da ortogonal?
- $a = -4$
+ $a = 4$
- $a = 0$
- $a = 2$
:::

---

## Ortogonal va ortonormal sistemalar

:::tarif
- **Ortogonal** sistema: har ikki vektori ortogonal.
- **Ortonormal**: qo'shimcha $|\mathbf e_i| = 1$, ya'ni $(\mathbf e_i, \mathbf e_j) = \delta_{ij}$.
:::

Masalan, $\mathbb R^3$ da $(1, 1, 0)$, $(1, -1, 0)$, $(0, 0, 1)$ — ortogonal; normallasak — ortonormal.

---

## Ortogonal sistema erkli

:::teorema
Noldan farqli o'zaro ortogonal vektorlar chiziqli erkli.
:::

Isbot: $\sum\lambda_i\mathbf e_i = \mathbf 0$ ni $\mathbf e_k$ ga skalyar ko'paytiramiz:
$$\lambda_k(\mathbf e_k, \mathbf e_k) = 0 \Rightarrow \lambda_k = 0.$$ ∎

Natija: $n$-o'lchamli fazoda $n$ ta noldan farqli ortogonal vektor — bazis.

---

## Ortonormal bazisda hisoblash

Agar $\mathbf e_1, \dots, \mathbf e_n$ — ortonormal bazis:
- $(\mathbf x, \mathbf y) = x_1y_1 + \dots + x_ny_n$;
- $|\mathbf x|^2 = x_1^2 + \dots + x_n^2$;
- **koordinatalar:** $x_i = (\mathbf x, \mathbf e_i)$.

Sistema yechish shart emas — faqat skalyar ko'paytmalar!

---

## Furye koeffitsiyentlari

:::tarif
$x_i = (\mathbf x, \mathbf e_i)$ — $\mathbf x$ ning **Furye koeffitsiyentlari**:
$$\mathbf x = \sum_i (\mathbf x, \mathbf e_i)\mathbf e_i.$$
:::

:::misol
$\mathbf e_1 = \frac{1}{\sqrt2}(1, 1)$, $\mathbf e_2 = \frac{1}{\sqrt2}(1, -1)$; $\mathbf x = (5, 1)$:
$$x_1 = \frac{6}{\sqrt2} = 3\sqrt2,\qquad x_2 = \frac{4}{\sqrt2} = 2\sqrt2.$$
:::

---

## Mashq: Furye koeffitsiyenti

:::savol
Ortonormal bazisda $\mathbf x$ ning $i$-koordinatasi?
- $|\mathbf x|$
+ $(\mathbf x, \mathbf e_i)$
- $|\mathbf e_i|$
- 1
:::

---

## Bessel tengsizligi va Parseval tengligi

Ortonormal $\mathbf e_1, \dots, \mathbf e_k$ uchun:
$$\sum_{i=1}^k(\mathbf x, \mathbf e_i)^2 \le |\mathbf x|^2\quad(\text{Bessel}).$$

Agar sistema bazis bo'lsa — tenglik (**Parseval**): «energiya» koeffitsiyentlar bo'yicha taqsimlanadi.

---

## Funksiyalardagi ortogonal sistema

$C[-\pi, \pi]$ da:
$$1,\ \cos t,\ \sin t,\ \cos 2t,\ \sin 2t,\ \dots$$
— ortogonal sistema: masalan $\int_{-\pi}^{\pi}\sin t\cos 2t\,dt = 0$.

**Furye qatori:** $f(t) = a_0 + \sum(a_k\cos kt + b_k\sin kt)$, koeffitsiyentlar — skalyar ko'paytmalar.

## Skalyar ko'paytma xossalari (natijalar)

Aksiomalardan:
- $(\mathbf x, \alpha\mathbf y + \beta\mathbf z) = \alpha(\mathbf x, \mathbf y) + \beta(\mathbf x, \mathbf z)$ — ikkinchi argument bo'yicha ham chiziqli;
- $(\mathbf 0, \mathbf x) = 0$;
- $|\mathbf x + \mathbf y|^2 + |\mathbf x - \mathbf y|^2 = 2|\mathbf x|^2 + 2|\mathbf y|^2$ — **parallelogramm qonuni**.

---

## Vaznli skalyar ko'paytma: misol

$\mathbb R^2$ da $(\mathbf x, \mathbf y) = 2x_1y_1 + 3x_2y_2$. Unda $(1, 0)$ va $(0, 1)$ ortogonal, lekin uzunliklari $\sqrt2$ va $\sqrt3$.

$\mathbf x = (1, 1)$, $\mathbf y = (3, -2)$: $(\mathbf x, \mathbf y) = 6 - 6 = 0$ — bu ko'paytmada ortogonal, standart ko'paytmada esa yo'q ($3 - 2 = 1$).

Ortogonallik — tanlangan skalyar ko'paytmaga bog'liq!

## Tipik xatolar

- Ortonormal bo'lmagan bazisda $(\mathbf x, \mathbf y) = \sum x_iy_i$ formulasini ishlatish.
- Normallashda ildizni unutish: $\mathbf x^0 = \mathbf x/|\mathbf x|$, $|\mathbf x|^2$ ga emas.
- $\cos\varphi$ formulasida maxrajni unutish.
- Ortogonallikni faqat nolmas vektorlar uchun erkliligini unutish.

---

## Xulosa

- Yevklid fazosi = chiziqli fazo + skalyar ko'paytma (4 aksioma).
- $|\mathbf x| = \sqrt{(\mathbf x, \mathbf x)}$, $\cos\varphi = \frac{(\mathbf x, \mathbf y)}{|\mathbf x||\mathbf y|}$.
- Koshi–Bunyakovskiy va uchburchak tengsizliklari.
- Ortogonal sistema erkli; ortonormal bazisda $x_i = (\mathbf x, \mathbf e_i)$.
