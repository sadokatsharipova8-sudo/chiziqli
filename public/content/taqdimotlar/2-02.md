## Hayotda

- **Ish:** kuch harakat yo'nalishiga burchak ostida — faqat «foydali» qismi ish bajaradi.
- **Quyosh panellari:** quyosh nuri va panel normali orasidagi burchak — olinadigan energiya.
- **Kompyuter grafikasi:** sirt yoritilganligi = yorug'lik va normal skalyar ko'paytmasi.
- **Tavsiya tizimlari:** foydalanuvchilar «o'xshashligi» — vektorlar orasidagi burchak kosinusi.

## O'q

:::tarif
**O'q** — yo'nalishi tanlangan to'g'ri chiziq. Uning birlik vektori $\mathbf l^0$.
:::

Vektor va o'q orasidagi burchak — vektor va $\mathbf l^0$ orasidagi burchak $\varphi \in [0, \pi]$.

---

## Proyeksiya

:::tarif
$\mathbf a$ ning $l$ o'qdagi **proyeksiyasi** — vektor boshi va oxiri proyeksiyalari orasidagi kesmaning **ishorali** uzunligi:
$$\text{pr}_l\,\mathbf a = |\mathbf a|\cos\varphi.$$
:::

---

## Proyeksiya ishorasi

| $\varphi$ | $\text{pr}_l\,\mathbf a$ |
|---|---|
| o'tkir ($< 90^\circ$) | musbat |
| $= 90^\circ$ | nol |
| o'tmas ($> 90^\circ$) | manfiy |

:::misol
$|\mathbf a| = 4$, $\varphi = 120^\circ$: $\text{pr} = 4\cdot\left(-\frac12\right) = -2$.
:::

---

## Proyeksiya xossalari

:::xossa
- $\text{pr}_l(\mathbf a + \mathbf b) = \text{pr}_l\mathbf a + \text{pr}_l\mathbf b$;
- $\text{pr}_l(\lambda\mathbf a) = \lambda\,\text{pr}_l\mathbf a$.
:::

Ya'ni proyeksiya — **chiziqli** amal (1-semestr 13-mavzu: chiziqli forma!).

Vektorning Dekart koordinatalari — $Ox$, $Oy$, $Oz$ o'qlaridagi proyeksiyalari.

---

## Yo'naltiruvchi kosinuslar

$\alpha, \beta, \gamma$ — $\mathbf a$ ning $Ox, Oy, Oz$ bilan burchaklari:
$$\cos\alpha = \frac{a_x}{|\mathbf a|},\quad \cos\beta = \frac{a_y}{|\mathbf a|},\quad \cos\gamma = \frac{a_z}{|\mathbf a|}.$$

:::xossa
$\cos^2\alpha + \cos^2\beta + \cos^2\gamma = 1$, $\quad\mathbf a^0 = (\cos\alpha;\ \cos\beta;\ \cos\gamma)$.
:::

---

## Yo'naltiruvchi kosinuslar: misol

$\mathbf a = (2;\ -1;\ 2)$, $|\mathbf a| = 3$:
$$\cos\alpha = \frac23,\quad \cos\beta = -\frac13,\quad \cos\gamma = \frac23.$$

Tekshirish: $\frac49 + \frac19 + \frac49 = 1$ ✓. $\cos\beta < 0$ — $Oy$ bilan o'tmas burchak.

---

## Mashq: yo'naltiruvchi kosinus

:::savol
Vektor $Ox$ va $Oy$ bilan $60^\circ$ dan burchak hosil qiladi. $\cos^2\gamma$?
- $\frac14$
+ $\frac12$
- $\frac34$
- $0$
> $1 - \frac14 - \frac14$.
:::

---

## Skalyar ko'paytma

:::tarif
$$\mathbf a\cdot\mathbf b = |\mathbf a|\,|\mathbf b|\cos\varphi.$$
:::

Boshqacha: $\mathbf a\cdot\mathbf b = |\mathbf a|\,\text{pr}_{\mathbf a}\mathbf b = |\mathbf b|\,\text{pr}_{\mathbf b}\mathbf a$.

Natija — **son** (skalyar), vektor emas!

---

## Xossalar

:::xossa
1. $\mathbf a\cdot\mathbf b = \mathbf b\cdot\mathbf a$
2. $(\lambda\mathbf a)\cdot\mathbf b = \lambda(\mathbf a\cdot\mathbf b)$
3. $\mathbf a\cdot(\mathbf b + \mathbf c) = \mathbf a\cdot\mathbf b + \mathbf a\cdot\mathbf c$
4. $\mathbf a\cdot\mathbf a = |\mathbf a|^2$
5. $\mathbf a \perp \mathbf b \iff \mathbf a\cdot\mathbf b = 0$
:::

Bu — Yevklid fazosi aksiomalari (1-semestr 11-mavzu)!

---

## Koordinatalarda

$\mathbf i\cdot\mathbf i = \mathbf j\cdot\mathbf j = \mathbf k\cdot\mathbf k = 1$, $\ \mathbf i\cdot\mathbf j = \mathbf j\cdot\mathbf k = \mathbf k\cdot\mathbf i = 0$.

Qavslarni ochib:
$$\mathbf a\cdot\mathbf b = a_xb_x + a_yb_y + a_zb_z.$$

---

## Misol

$(1;\ 2;\ 3)\cdot(4;\ -5;\ 6) = 4 - 10 + 18 = 12.$

$(1;\ 2;\ -2)\cdot(2;\ 1;\ 2) = 2 + 2 - 4 = 0$ — perpendikulyar.

---

## Tatbiq 1: burchak

$$\cos\varphi = \frac{\mathbf a\cdot\mathbf b}{|\mathbf a||\mathbf b|} = \frac{a_xb_x + a_yb_y + a_zb_z}{\sqrt{a_x^2 + a_y^2 + a_z^2}\sqrt{b_x^2 + b_y^2 + b_z^2}}.$$

:::misol
$\mathbf a = (1;\ 0;\ 1)$, $\mathbf b = (0;\ 1;\ 1)$: $\cos\varphi = \frac{1}{\sqrt2\sqrt2} = \frac12$, $\varphi = 60^\circ$.
:::

---

## Uchburchak burchagi

$A(2;\ 3;\ 2)$, $B(-2;\ -1;\ 1)$, $C(1;\ 1;\ 1)$. $C$ burchak:
$$\overrightarrow{CA} = (1;\ 2;\ 1),\quad \overrightarrow{CB} = (-3;\ -2;\ 0),$$
$$\cos C = \frac{-3 - 4 + 0}{\sqrt6\sqrt{13}} = -\frac{7}{\sqrt{78}}.$$

Burchak **o'tmas** (kosinus manfiy).

---

## Tatbiq 2: proyeksiya

$$\text{pr}_{\mathbf b}\mathbf a = \frac{\mathbf a\cdot\mathbf b}{|\mathbf b|}.$$

:::misol
$\mathbf a = (2;\ 1;\ 2)$ ning $\mathbf b = (1;\ 2;\ 2)$ dagi proyeksiyasi: $\frac{2 + 2 + 4}{3} = \frac83$.
:::

:::savol
$\mathbf a = (1;\ 2;\ -2)$ ning $\mathbf b = (2;\ 1;\ 2)$ dagi proyeksiyasi?
+ $0$
- $\frac83$
- $1$
- $-\frac23$
:::

---

## Tatbiq 3: perpendikulyarlik

$\mathbf a = (2;\ -1;\ 3)$, $\mathbf b = (1;\ k;\ -1)$:
$$\mathbf a\cdot\mathbf b = 2 - k - 3 = 0 \Rightarrow k = -1.$$

Mashqlar bo'limidagi «Perpendikulyarlik sharti» masalalari shunday.

---

## Tatbiq 4: ish

$\mathbf F$ kuch nuqtani $\mathbf s$ ga ko'chirganda:
$$A = \mathbf F\cdot\mathbf s.$$

:::misol
$\mathbf F = (3;\ -2;\ 1)$, $M_1(1;\ 0;\ 2) \to M_2(3;\ 1;\ 5)$: $\mathbf s = (2;\ 1;\ 3)$, $A = 6 - 2 + 3 = 7$.
:::

Kuch harakatga perpendikulyar bo'lsa — ish nol (masalan, aylana bo'ylab harakatda markazga intilma kuch).

---

## Tatbiq 5: kosinuslar teoremasi

$$|\mathbf a + \mathbf b|^2 = (\mathbf a + \mathbf b)\cdot(\mathbf a + \mathbf b) = |\mathbf a|^2 + 2\,\mathbf a\cdot\mathbf b + |\mathbf b|^2.$$

:::savol
$|\mathbf a| = 3$, $|\mathbf b| = 4$, $\varphi = 60^\circ$. $(\mathbf a + \mathbf b)^2$?
- 25
+ 37
- 49
- 13
:::

---

## Tatbiq 6: rombning diagonallari

Romb: $|\mathbf a| = |\mathbf b|$. Diagonallar $\mathbf a + \mathbf b$ va $\mathbf a - \mathbf b$:
$$(\mathbf a + \mathbf b)\cdot(\mathbf a - \mathbf b) = |\mathbf a|^2 - |\mathbf b|^2 = 0.$$

Diagonallar perpendikulyar — bir qatorda isbot!

---

## Tatbiq 7: o'xshashlik o'lchovi

Matnlar «so'zlar chastotasi» vektorlari bilan ifodalanadi. Ikki matn o'xshashligi:
$$\cos\varphi = \frac{\mathbf a\cdot\mathbf b}{|\mathbf a||\mathbf b|}.$$

$\cos\varphi \approx 1$ — mavzulari yaqin. Qidiruv tizimlari va ChatGPT kabi modellar shu «kosinus o'xshashligi»dan foydalanadi.

## Vektor proyeksiyasi (vektor ko'rinishida)

Son emas, vektor kerak bo'lsa:
$$\overrightarrow{\text{pr}}_{\mathbf b}\mathbf a = \frac{\mathbf a\cdot\mathbf b}{|\mathbf b|^2}\mathbf b.$$

:::misol
$\mathbf a = (3;\ 4)$, $\mathbf b = (1;\ 0)$: $\overrightarrow{\text{pr}} = \frac31(1;\ 0) = (3;\ 0)$; qoldiq $(0;\ 4) \perp \mathbf b$.
:::

---

## Skalyar ko'paytma va uzunlik

$$|\mathbf a - \mathbf b|^2 = |\mathbf a|^2 - 2\,\mathbf a\cdot\mathbf b + |\mathbf b|^2.$$

:::misol
$|\mathbf a| = 2$, $|\mathbf b| = 3$, $\mathbf a\cdot\mathbf b = 3$: $|\mathbf a - \mathbf b| = \sqrt{4 - 6 + 9} = \sqrt7$.
:::

---

## Mashq: burchak

:::savol
$\mathbf a = (1;\ 1;\ 0)$, $\mathbf b = (1;\ 0;\ 1)$ orasidagi burchak?
- $30^\circ$
- $45^\circ$
+ $60^\circ$
- $90^\circ$
> $\cos\varphi = \frac{1}{\sqrt2\cdot\sqrt2} = \frac12$.
:::

## Tipik xatolar

- Skalyar ko'paytmani vektor deb yozish.
- $\cos\varphi$ ni topishda uzunliklarni ildizsiz qoldirish.
- Proyeksiyada $|\mathbf a|$ ga bo'lish ($|\mathbf b|$ kerak — qaysi vektorga proyeksiyalayotganimiz).
- Burchak o'tmasligini unutib, ishorani tashlab yuborish.

---

## Xulosa

- $\text{pr}_l\,\mathbf a = |\mathbf a|\cos\varphi$ — chiziqli.
- $\cos^2\alpha + \cos^2\beta + \cos^2\gamma = 1$.
- $\mathbf a\cdot\mathbf b = |\mathbf a||\mathbf b|\cos\varphi = a_xb_x + a_yb_y + a_zb_z$.
- Tatbiqlar: burchak, proyeksiya, perpendikulyarlik, ish, uzunlik.
