## II qism: analitik geometriya

**G'oya** (Dekart, Ferma, XVII asr): geometrik obyektlarni **sonlar va tenglamalar** orqali o'rganish.

- Nuqta $\leftrightarrow$ koordinatalar
- Chiziq, sirt $\leftrightarrow$ tenglama
- Geometrik masala $\leftrightarrow$ algebraik masala

Asosiy vosita — **vektorlar**, ular I qismdagi chiziqli algebrani geometriyaga bog'laydi.

---

## Vektor

:::tarif
Yo'nalgan kesma — **vektor**: $\overrightarrow{AB}$ yoki $\mathbf a$.
- $A$ — boshi, $B$ — oxiri
- $|\mathbf a|$ — uzunligi (moduli)
:::

Fizikada: kuch, tezlik, tezlanish, elektr maydon kuchlanganligi — vektor kattaliklar. Massa, temperatura — skalyar.

---

## Vektorlar tengligi

:::tarif
Uzunliklari teng va yo'nalishlari bir xil vektorlar **teng**.
:::

- Vektorni parallel ko'chirsak, u o'zgarmaydi — **erkin vektorlar**.
- **Nol vektor** $\mathbf 0$: boshi va oxiri ustma-ust, yo'nalishi aniqlanmagan.
- **Birlik vektor** (ort): $|\mathbf a| = 1$.
- **Qarama-qarshi** vektor $-\mathbf a$: uzunligi teng, yo'nalishi teskari.

---

## Kollinear va komplanar

:::tarif
- **Kollinear** — bitta to'g'ri chiziqda yoki parallel to'g'ri chiziqlarda yotadi: $\mathbf a \parallel \mathbf b$.
- **Komplanar** — bitta tekislikda yoki parallel tekisliklarda yotadi.
:::

- Istalgan ikki vektor komplanar.
- Nol vektor har qanday vektorga kollinear.

---

## Qo'shish

**Uchburchak qoidasi:** $\mathbf b$ ning boshini $\mathbf a$ ning oxiriga qo'yamiz; $\mathbf a + \mathbf b$ — $\mathbf a$ boshidan $\mathbf b$ oxirigacha.

**Parallelogramm qoidasi:** umumiy boshdan qo'yilgan $\mathbf a$, $\mathbf b$ ga qurilgan parallelogramm diagonali.

**Ko'pburchak qoidasi:** $\overrightarrow{AB} + \overrightarrow{BC} + \overrightarrow{CD} = \overrightarrow{AD}$.

Ayirish: $\mathbf a - \mathbf b = \mathbf a + (-\mathbf b)$ — ikkinchi diagonal.

---

## Songa ko'paytirish

$\lambda\mathbf a$:
- uzunligi $|\lambda|\,|\mathbf a|$;
- $\lambda > 0$ — yo'nalish bir xil, $\lambda < 0$ — teskari;
- $\lambda = 0$ — nol vektor.

Ortga keltirish: $\mathbf a^0 = \dfrac{\mathbf a}{|\mathbf a|}$.

Amallar 8 aksiomani qanoatlantiradi — geometrik vektorlar **chiziqli fazo** ($V_3$).

---

## Chiziqli bog'liqlik — geometrik ma'no

:::teorema
1. Ikki vektor kollinear $\iff$ chiziqli bog'liq: $\mathbf b = \lambda\mathbf a$.
2. Uch vektor komplanar $\iff$ chiziqli bog'liq.
3. Fazoda istalgan to'rtta vektor chiziqli bog'liq.
:::

Natija: $\dim V_2 = 2$, $\dim V_3 = 3$. Fazoda istalgan uchta nokomplanar vektor — bazis.

---

## Dekart bazisi

$\mathbf i, \mathbf j, \mathbf k$ — o'zaro perpendikulyar birlik vektorlar (ortonormal bazis):
$$\mathbf a = a_x\mathbf i + a_y\mathbf j + a_z\mathbf k = (a_x;\ a_y;\ a_z).$$

$a_x, a_y, a_z$ — vektorning koordinatalari (koordinata o'qlaridagi proyeksiyalari).

---

## Koordinatalarda amallar

:::xossa
- $\overrightarrow{AB} = (x_2 - x_1;\ y_2 - y_1;\ z_2 - z_1)$ — **oxiridan boshini ayiramiz**
- $\mathbf a \pm \mathbf b = (a_x \pm b_x;\ a_y \pm b_y;\ a_z \pm b_z)$
- $\lambda\mathbf a = (\lambda a_x;\ \lambda a_y;\ \lambda a_z)$
- $\mathbf a \parallel \mathbf b \iff \dfrac{a_x}{b_x} = \dfrac{a_y}{b_y} = \dfrac{a_z}{b_z}$
:::

---

$A(1;\ 2)$, $B(4;\ 6)$. $\overrightarrow{AB}$ = ?
- $(5;\ 8)$

- $(-3;\ -4)$
- $(4;\ 3)$
:::

## Uzunlik

$$|\mathbf a| = \sqrt{a_x^2 + a_y^2 + a_z^2}.$$

Ikki nuqta orasidagi masofa:
$$|AB| = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}.$$

:::misol
$\mathbf a = (2;\ -1;\ 2)$: $|\mathbf a| = \sqrt{4 + 1 + 4} = 3$.
:::

---

## Yo'naltiruvchi kosinuslar

$\alpha, \beta, \gamma$ — $\mathbf a$ ning $Ox, Oy, Oz$ bilan burchaklari:
$$\cos\alpha = \frac{a_x}{|\mathbf a|},\quad \cos\beta = \frac{a_y}{|\mathbf a|},\quad \cos\gamma = \frac{a_z}{|\mathbf a|}.$$

:::xossa
$\cos^2\alpha + \cos^2\beta + \cos^2\gamma = 1$, $\quad \mathbf a^0 = (\cos\alpha;\ \cos\beta;\ \cos\gamma)$.
:::

---

## Yo'naltiruvchi kosinuslar: misol

$\mathbf a = (2;\ -1;\ 2)$, $|\mathbf a| = 3$:
$$\cos\alpha = \frac23,\qquad \cos\beta = -\frac13,\qquad \cos\gamma = \frac23.$$

Tekshirish: $\frac49 + \frac19 + \frac49 = 1$ ✓

$\cos\beta < 0$ — vektor $Oy$ bilan o'tmas burchak hosil qiladi.

---

## Kesmani nisbatda bo'lish

$M$ nuqta $AB$ ni $\dfrac{AM}{MB} = \lambda$ nisbatda bo'ladi:
$$x_M = \frac{x_1 + \lambda x_2}{1 + \lambda},\quad y_M = \frac{y_1 + \lambda y_2}{1 + \lambda},\quad z_M = \frac{z_1 + \lambda z_2}{1 + \lambda}.$$

Isbot: $\overrightarrow{AM} = \lambda\overrightarrow{MB}$ ni koordinatalarda yozamiz.

---

## Xususiy hollar

- **O'rta nuqta** ($\lambda = 1$): $M = \left(\dfrac{x_1 + x_2}{2};\ \dfrac{y_1 + y_2}{2};\ \dfrac{z_1 + z_2}{2}\right)$.
- **Uchburchak og'irlik markazi**: uchlar koordinatalarining o'rta arifmetigi:
$$G = \left(\frac{x_1 + x_2 + x_3}{3};\ \frac{y_1 + y_2 + y_3}{3};\ \frac{z_1 + z_2 + z_3}{3}\right).$$

---

## Misol: parallelogramm

Parallelogrammning uchlari $A(1;\ 2)$, $B(5;\ 3)$, $C(6;\ 7)$. $D$ = ?

Diagonallar kesishish nuqtasida teng ikkiga bo'linadi:
- $AC$ o'rtasi: $(3{,}5;\ 4{,}5)$
- $BD$ o'rtasi ham shu: $D = (2\cdot3{,}5 - 5;\ 2\cdot4{,}5 - 3) = (2;\ 6)$.

Vektorlar bilan: $\overrightarrow{AD} = \overrightarrow{BC} = (1;\ 4)$, $D = A + (1;\ 4) = (2;\ 6)$ ✓

## O'qdagi proyeksiya

:::tarif
$$\text{pr}_l\,\mathbf a = |\mathbf a|\cos\varphi,$$
$\varphi$ — vektor va $l$ o'q orasidagi burchak.
:::

- $\varphi$ o'tkir — proyeksiya musbat
- $\varphi = 90^\circ$ — nol
- $\varphi$ o'tmas — manfiy

:::xossa
$\text{pr}_l(\mathbf a + \mathbf b) = \text{pr}_l\mathbf a + \text{pr}_l\mathbf b$, $\quad\text{pr}_l(\lambda\mathbf a) = \lambda\,\text{pr}_l\mathbf a$.
:::

---

## Skalyar ko'paytma

:::tarif
$$\mathbf a\cdot\mathbf b = |\mathbf a|\,|\mathbf b|\cos\varphi.$$
:::

Boshqacha: $\mathbf a\cdot\mathbf b = |\mathbf a|\,\text{pr}_{\mathbf a}\mathbf b = |\mathbf b|\,\text{pr}_{\mathbf b}\mathbf a$.

Natija — **son** (skalyar), vektor emas.

---

## Skalyar ko'paytma xossalari

:::xossa
1. $\mathbf a\cdot\mathbf b = \mathbf b\cdot\mathbf a$
2. $(\lambda\mathbf a)\cdot\mathbf b = \lambda(\mathbf a\cdot\mathbf b)$
3. $\mathbf a\cdot(\mathbf b + \mathbf c) = \mathbf a\cdot\mathbf b + \mathbf a\cdot\mathbf c$
4. $\mathbf a\cdot\mathbf a = |\mathbf a|^2$
5. $\mathbf a \perp \mathbf b \iff \mathbf a\cdot\mathbf b = 0$
:::

Bu — 9-mavzudagi Yevklid fazosi aksiomalari!

## Koordinatalarda

$\mathbf i\cdot\mathbf i = \mathbf j\cdot\mathbf j = \mathbf k\cdot\mathbf k = 1$, $\ \mathbf i\cdot\mathbf j = \mathbf j\cdot\mathbf k = \mathbf k\cdot\mathbf i = 0$. Shuning uchun:
$$\mathbf a\cdot\mathbf b = a_xb_x + a_yb_y + a_zb_z.$$

:::misol
$(1;\ 2;\ 3)\cdot(4;\ -5;\ 6) = 4 - 10 + 18 = 12$.
:::

---

## Tatbiq 1: burchak

$$\cos\varphi = \frac{\mathbf a\cdot\mathbf b}{|\mathbf a|\,|\mathbf b|} = \frac{a_xb_x + a_yb_y + a_zb_z}{\sqrt{a_x^2 + a_y^2 + a_z^2}\sqrt{b_x^2 + b_y^2 + b_z^2}}.$$

:::misol
Uchburchak $A(2;\ 3;\ 2)$, $B(-2;\ -1;\ 1)$, $C(1;\ 1;\ 1)$. $\overrightarrow{CA} = (1;\ 2;\ 1)$, $\overrightarrow{CB} = (-3;\ -2;\ 0)$:
$$\cos C = \frac{-3 - 4 + 0}{\sqrt6\cdot\sqrt{13}} = -\frac{7}{\sqrt{78}}\ \text{— burchak o'tmas.}$$
:::

---

## Tatbiq 2: proyeksiya

$$\text{pr}_{\mathbf b}\mathbf a = \frac{\mathbf a\cdot\mathbf b}{|\mathbf b|}.$$

:::savol
$\mathbf a = (1;\ 2;\ -2)$ ning $\mathbf b = (2;\ 1;\ 2)$ dagi proyeksiyasi?
+ $0$
- $\frac83$
- $1$
- $-\frac23$
> $2 + 2 - 4 = 0$ — vektorlar perpendikulyar.
:::

---

## Tatbiq 3: ish

$\mathbf F$ kuch jismni $\mathbf s$ ko'chishga siljitganda bajarilgan **ish**:
$$A = \mathbf F\cdot\mathbf s = |\mathbf F|\,|\mathbf s|\cos\varphi.$$

:::misol
$\mathbf F = (3;\ -2;\ 1)$, nuqta $M_1(1;\ 0;\ 2)$ dan $M_2(3;\ 1;\ 5)$ ga ko'chdi: $\mathbf s = (2;\ 1;\ 3)$,
$$A = 6 - 2 + 3 = 7.$$
:::

---

## Tatbiq 4: kosinuslar teoremasi

$$|\mathbf a + \mathbf b|^2 = (\mathbf a + \mathbf b)^2 = |\mathbf a|^2 + 2\,\mathbf a\cdot\mathbf b + |\mathbf b|^2.$$

:::savol
$|\mathbf a| = 3$, $|\mathbf b| = 4$, $\varphi = 60^\circ$. $(\mathbf a + \mathbf b)^2$ = ?
- 25
+ 37
- 49
- 13
> $9 + 2\cdot 6 + 16 = 37$.
:::

## Perpendikulyarlik: misol

$\mathbf a = (2;\ -1;\ 3)$ va $\mathbf b = (1;\ k;\ -1)$ qachon perpendikulyar?
$$2 - k - 3 = 0 \Rightarrow k = -1.$$

Mashqlar bo'limidagi «perp» masalalari aynan shunday.

## Tipik xatolar

- $\overrightarrow{AB}$ da boshidan oxirini ayirish.
- Skalyar ko'paytma natijasini vektor deb yozish.
- $\cos\varphi$ dan burchakni topishda $|\mathbf a|$, $|\mathbf b|$ ni ildizsiz qoldirish.
- Proyeksiyada $|\mathbf a|$ ga emas, $|\mathbf b|$ ga bo'lish kerakligini chalkashtirish.

---

## Xulosa

- Vektor — yo'nalgan kesma; erkin vektorlar chiziqli fazo $V_3$.
- Dekart bazisi $\mathbf i, \mathbf j, \mathbf k$ — ortonormal.
- $\cos^2\alpha + \cos^2\beta + \cos^2\gamma = 1$.
- $\mathbf a\cdot\mathbf b = |\mathbf a||\mathbf b|\cos\varphi = a_xb_x + a_yb_y + a_zb_z$.
- Tatbiqlar: burchak, proyeksiya, perpendikulyarlik, ish.
